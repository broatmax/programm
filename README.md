Данная программа поможет смоделировать вам распространение тепла в пластине. Вы сами выбираете материал из представленного списка, сами выстраиваете нужную вам пластину, размещаете источники и наблюдаете процесс распространения тепла! Программа позволяет сохранять сценарии ваших пластин, чтобы можно было вернуться к ним в будущем.
